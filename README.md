# DoctorAppointment2.0

An Android application for managing medical appointments across three user roles — **Patients**, **Doctors**, and **Nurses**.

Patients can register and log in with email, browse doctors, and book appointments. Doctors and nurses can view their upcoming appointments and record notes on past visits.

> 📹 **[Watch the demo](https://youtube.com/shorts/p-f_ZaY2yiU)**

---

## Overview

DoctorAppointment2.0 streamlines the appointment workflow between patients and care providers in a single mobile app. Each role sees a tailored view: patients focus on finding doctors and booking, while doctors and nurses manage their schedules and patient records.

This project was built as the **Final Project for CS207 – Object-Oriented Software Design** at **Fulbright University Vietnam** (Fall 2023), as a group effort.

## User Roles

- **Patient** — the primary user. Registers an account, logs in via email, selects a doctor, and books appointments.
- **Doctor** — views upcoming appointments and records data about past visits.
- **Nurse** — views upcoming appointments and records data about past visits.

## Features

- Email-based account registration and login
- Doctor selection and appointment booking for patients
- Upcoming-appointment views for doctors and nurses
- Recording and reviewing data from past appointments
- Role-based interface — each user type gets a relevant view
